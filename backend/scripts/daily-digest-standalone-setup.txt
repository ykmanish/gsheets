You are setting up the "Raga Daily Digest" — an executive status page for raga (an interiors/construction company) — from scratch on this account, using the raga-mongo MCP connector. This has two parts: (1) build and publish it once right now, (2) create a scheduled task so it refreshes itself every night at 8 PM. Work autonomously; don't ask the user anything except tool-permission prompts.

PART 1 — BUILD AND PUBLISH IT NOW
============================================================

STEP 1 — Load tools
ToolSearch "select:mcp__raga-mongo__aggregate,mcp__raga-mongo__find,mcp__raga-mongo__count" (retry once if raga-mongo hasn't connected yet). All calls use connectionId "preconfigured", database "sheets".

STEP 2 — Get today's date/time
Run: date +"%Y-%m-%d | %-d %B %Y | %-d %b | %-I:%M %p"
If that machine's date binary doesn't support IST directly, DO NOT prefix with TZ= (some environments silently fall back to UTC when TZ is set and have no tzdata) — use the plain system clock time and note in your summary if the result looks wrong. This gives `today` (YYYY-MM-DD), a long display date, and a time string.

STEP 3 — Query every section (raga-mongo, database "sheets")

A) Attendance — `hrAttendanceRecords` (field `date` is a STRING) + `users`:
   find(hrAttendanceRecords, {"date":today}, projection {employeeName:1, userId:1, status:1, workMode:1}) → today's records.
   find(users, {"blacklisted":{"$ne":true},"isSuperAdmin":{"$ne":true}}, projection {displayName:1}) → active roster names.
   presentNames = employeeName list from today's records (tag "remote" if workMode=="remote", "done" if status=="completed", else no tag). presentCount = length. officeCheckedInCount/remoteCheckedInCount/completedCount from status+workMode combos.
   Reconciliation (normal, not a bug, if a few present people fall outside the roster query): totalRoster = union by name of (roster names) and (presentNames). absentNames = roster names not in presentNames. noRecordCount = absentNames.length. Must always satisfy presentCount + noRecordCount == totalRoster.

B) Manpower (DMR) — `dmrDailySnapshots` (field `date` is a STRING, one doc per linked spreadsheet/site-group):
   aggregate: [{"$match":{"date":today}},{"$group":{"_id":null,"planned":{"$sum":"$totals.planned"},"actual":{"$sum":"$totals.actual"},"filled":{"$sum":"$totals.filled"},"records":{"$sum":"$totals.records"},"siteCount":{"$sum":1}}}]
   planned/actual = headcounts. filled/records = row-fill counts. Zero/low is normal early in the day — represent honestly.
   Per-site: aggregate [{"$match":{"date":today}},{"$unwind":"$siteBreakdown"},{"$group":{"_id":"$siteBreakdown.label","planned":{"$sum":"$siteBreakdown.planned"},"actual":{"$sum":"$siteBreakdown.actual"},"records":{"$sum":"$siteBreakdown.records"},"filled":{"$sum":"$siteBreakdown.filled"}}},{"$sort":{"actual":-1}}] → dmrBySite list. sitesReportingCount = sites where actual>0.

C) Stock by site — `stockDailySnapshots` (one doc/date, unique on date), fallback `stockSiteSnapshots`:
   find({"date":today}) projection {date:1,"sites.name":1,"sites.summary":1}. If none, find({}) sorted {date:-1} limit 1, same projection. If still nothing, aggregate stockSiteSnapshots grouped by siteName.
   sites[] → stockBySite table (Site, Items tracked, Qty on hand, Low stock), sorted by low stock descending. totalLowStock + sitesWithLowStock + totalSiteCount.

D) Delayed tasks — `projectDashboard` (single doc, _id:"default", tasks under config.projects[].phases[].tasks[]):
   aggregate: [{"$project":{"projects":"$config.projects"}},{"$unwind":"$projects"},{"$unwind":"$projects.phases"},{"$unwind":"$projects.phases.tasks"},{"$project":{"projectName":"$projects.name","phaseName":"$projects.phases.name","title":"$projects.phases.tasks.title","status":"$projects.phases.tasks.status","dueDate":"$projects.phases.tasks.dueDate","priority":"$projects.phases.tasks.priority","startDate":"$projects.phases.tasks.startDate"}},{"$facet":{"delayed":[{"$match":{"status":{"$ne":"done"},"dueDate":{"$ne":"","$lt":today}}},{"$sort":{"dueDate":1}}],"startingToday":[{"$match":{"startDate":today}},{"$count":"count"}]}}]
   Status vocabulary here is "todo"/"in_progress"/"done". Group delayed by projectName → delayedByProject = [{name, tasks:[{phase,title,due,days,priority}]}], oldest-due-first per project, projects sorted worst-first. delayedTotal/delayedProjectCount. startingTodayCount = startingToday[0]?.count || 0.

E) Employee report — `employeeDailyReports` (field `reportDate` is a STRING):
   count({"reportDate":today}) → submittedCount. Denominator = totalRoster from step A.
